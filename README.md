# Supply Chain & Delivery Performance Analytics Dashboard

## Project Overview

This project focuses on analyzing supply chain operations, shipping efficiency, and delivery performance using Tableau. The interactive dashboard helps explore order distribution, shipping delays, and delivery performance across different shipping modes, regions, and product categories.

## Objectives

- Analyze total orders and late shipment performance.
- Track monthly shipping efficiency and late shipment trends.
- Compare shipping performance across shipping modes.
- Identify product categories with higher late shipment rates.
- Explore order volume across different regions.
- Enable interactive analysis using dashboard filters.

## Tools & Technologies

- **Tableau:** Interactive dashboards and data visualization
- **Data Analysis:** KPI analysis and performance monitoring
- **Data Preparation:** Data cleaning and transformation

## Dashboard Highlights

### 1. Executive Overview
Displays key performance indicators, including total orders, late shipment rate, average actual shipping days, and late shipment orders.

### 2. Monthly Shipping Efficiency
Visualizes monthly actual and scheduled shipping performance alongside the late shipment rate.

### 3. Shipping Mode Analysis
Compares shipping performance and late shipment rates across different shipping modes.

### 4. Regional Order Analysis
Explores order volume across geographical regions.

### 5. Product Category Analysis
Compares late shipment rates across product categories.

### 6. Shipping Duration Analysis
Explores the relationship between actual shipping duration and late shipment rate.
